# Zukei Puzzle

Zukei puzzles are shape puzzles where players must find the vertices of various geometric shapes hidden within a grid of dots.

This project implements an interactive Zukei puzzle generator with guidance available to help players find shapes.

### Background

[Zukei puzzles](https://mathequalslove.net/zukei-puzzles/) were originally created by puzzle creator Naoki Inaba.
